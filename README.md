## 🧠 The AI & Systems Engine
### Flagship: [ProblemFinder-AI](https://github.com/jahnavik1125/ProblemFinder-AI)

> **"Give me a technology. I'll find the problems it can solve, the industries that need it, and the opportunities hiding there."**

ProblemFinder-AI is an intelligent opportunity-discovery platform that bridges raw, emerging tech capability with concrete, operational problem-solving. It moves away from standard "LLM wrappers" by implementing a structured analytical pipeline.

```
                      [ TECHNOLOGY INPUT ]
                               │
                               ▼
                   [ SEMANTIC VECTOR SEARCH ]
            Embedded query matches against problems DB
             (Sentence-Transformers + FAISS Index)
                               │
                               ▼
                    [ KNOWLEDGE GRAPH MESH ]
         Extracts relationships: Tech ➔ Industry ➔ Problem
                               │
                               ▼
                   [ OPPORTUNITY EVALUATION ]
           Computes weighted score based on Severity,
           Feasibility, Competitor Proxy, and Tech Fit
                               │
                               ▼
                     [ LLM REASONING LAYER ]
           Enriches insights with Gemini 1.5 Flash API
            (Deterministic local template fallback)
                               │
                               ▼
                    [ OPPORTUNITY DASHBOARD ]
               Interactive, score-ranked cards
```

#### Key Technical Contributions:
*   **Vector Search Engine**: Implemented FAISS search utilizing the `all-MiniLM-L6-v2` sentence-transformer for semantic queries.
*   **Knowledge Graph representation**: Developed an in-memory pythonic graph showing relationships between 15 emerging technologies, 10 industries, and 40+ operational problems.
*   **Weighted Scoring Algorithm**: Engineered a scoring engine evaluating severity, market potential, entry barriers, feasibility, and technical fit into a single composite Opportunity Score.
*   **Graceful API Degradation**: Designed a zero-dependency local template engine that serves as a seamless fallback if the Gemini API is offline or throttled.
